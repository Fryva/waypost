## Description

Isolate the existing Markdown table cell writer/reader contract so agents can inspect it without reading the entire shared library. Keep the literal String(s) coercion and pipe/backslash rules, public API and callers. This small mechanical step is not evidence of net token savings and adds no new policy or ADR.

## Decomposition

- [x] Freeze source, API and behavior before editing.
- [x] Extract literal block and add focused coercion/escaping/consumer checks.
- [x] Run affected tests, package/doctor and independent final review.

## Implementation Plan

Move the complete760B Markdown table cell escaping block into scripts/lib-markdown-cells.mjs with no imports/state; directly re-export escCell/unescCell from lib.mjs, both arity1. No internal callers exist in the facade. Dates and heading/cache ownership remain unchanged. Leaf ceiling1500B. Prove full inverse reconstruction, namespace100 and unchanged function-source metadata.

Freeze a corpus covering empty/plain/ASCII pipe, already escaped pipe, consecutive backslashes/pipes, Unicode/fullwidth pipe, CR/LF and String coercion including objects and errors. Preserve deliberate non-idempotence; no general Markdown parsing, normalization or new validation. Verify original thrown error identity. Compare one owned generated-index fixture with a title containing pipe, escaped pipe and Unicode, then read it using doctor checkIndexes; compare bytes and diagnostics before/after and keep protected source identities. Focused tests pin facade bindings/name/arity/budget and consumer round trip. Run focused, predicates, scripts and doctor-generated tests through waypost run --heavy with source-bound runtime/log receipts; package dry-run, syntax and doctor. Fresh reviewer before close/commit. Full supported Node CI after publication, status stated honestly.
