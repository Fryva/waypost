HTTP API:

POST /api/notes accepts exactly {title,body}, creates and returns201 {note:complete-record}.
GET /api/notes/:id returns200 {note} or404.
PATCH /api/notes/:id accepts a nonempty subset of title/body only; returns200 {note} or404. Unknown properties, invalid types/lengths =>400.
DELETE /api/notes/:id returns200 {deleted:id} or404.
GET /api/export returns exact backup {version:1,notes:[...]}.
POST /api/import accepts only a valid exact backup schema, with unique ids, no unknown fields, all records validated before commit; replaces the whole collection atomically and returns200 {imported:number}. Invalid backup =>400; too many notes/oversize state=>413. Invalid imports must leave the prior state unchanged.
