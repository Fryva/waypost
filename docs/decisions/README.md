# Architecture Decision Records

The decision log moved into Waypost's own vault on 2026-09-04:
[`docs/vault/adr/`](../vault/adr/README.md). The index there is maintained by
`waypost reconcile`; a new decision is drafted with `waypost draft adr "<title>" --write`
and stays `proposed` until the project owner approves it, after a fresh-context
critic pass (`waypost-critic`).
