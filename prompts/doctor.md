You are running waypost diagnostics.

## Steps

1. **Run the engine** (read-only; pass through the section flags, never `--fix` yet):

   ```bash
   waypost doctor $ARGUMENTS_WITHOUT_FIX
   ```

   With no flags it runs both sections: `--install` (bind, templates, roles,
   routing block, gitignore, vault git) and `--vault` (consistency). Print the
   report **verbatim** — the findings are the product, not your summary of them.

2. **No issues** → done. One line: "Doctor is clean — N info note(s) above."

3. **`--fix` requested** → say which repairs it will make, get the user's go-ahead,
   then run `waypost doctor --fix`. It is deliberately mechanical and reversible:

   - `gitignore` → appends the machine-specific entries.
   - `vault-git` → `git init` in the vault.
   - `agent-roles` stale/missing → re-renders them from `agents/*.md` for the
     harnesses this project uses (`waypost agents install`).
   - `agents-block` version drift → rewrites the routing block in place.

   **Boundary**: `--fix` never repairs vault-side findings. Those go through
   `waypost reconcile --write` (indexes, kanban, code-map, graph). Never hand-edit an
   index row or a board card: derived views are only ever written by regeneration.

4. **Judgement findings are not repairs.** `work-without-story` reports that the
   project tree has uncommitted source work while no story is `in-progress`. The
   answer is a decision — open the story
   (`waypost draft story <EPIC> "<title>" --write`), or accept that the change is a
   one-off. Do not present it as fixable by a command.

   `agent-roles` reported as `foreign` means a file under the `waypost-` prefix was
   not generated by waypost. Never overwrite it silently: ask whether it is the
   user's own agent, and rename rather than clobber.

## Notes

- Detection is read-only by contract; only `--fix` writes, and only what is
  listed above.
- The install section is harness-aware: it reports a harness only when the
  project uses it (a `.claude/`, `.opencode/` or `.codex/` directory, or an
  instruction file), so a Codex-only project never hears about `.claude/agents`.
- `waypost doctor --json` is the machine-readable form — use it when you need to
  branch on findings rather than show them.
